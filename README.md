# SoloTilt App

A native mobile app with tilt/gyroscope effects similar to solotilt.com.

## Features
- 🎨 Tilt-responsive visual effects
- 📱 Works on Android & iOS
- 🔓 100% Free (MIT License)
- ⚡ GPU-accelerated smooth animations

## Build Instructions

### Prerequisites
- Install Flutter: https://docs.flutter.dev/get-started/install
- Android Studio or VS Code with Flutter extension

### Clone & Run
```bash
git clone [https://github.com/YOUR_USERNAME/solotilt-app.git](https://github.com/YOUR_USERNAME/solotilt-app.git)
cd solotilt-app
flutter pub get
flutter run
