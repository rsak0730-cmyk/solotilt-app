# SoloTilt App

A native mobile app with tilt/gyroscope effects similar to solotilt.com.

## Features
- 🎨 Tilt-responsive visual effects
- 📱 Works on Android & iOS
- 🔓 100% Free (MIT License)
- ⚡ GPU-accelerated smooth animations
